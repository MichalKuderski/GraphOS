      Create a run

      Creating a run queues work. It does not start a model call. A configured worker must execute it; a deterministic fixture run is always labeled as such.

      New specification revision

      Revise the specification

      This creates a new revision, invalidates this run’s current verification, and stops older worker attempts from submitting results. Outstanding reservations are charged conservatively; unresolved provider costs still require reconciliation.

      The registered task, objective, and acceptance criteria are preserved. This milestone supports the three registered app contracts; arbitrary build requirements are not accepted.

      Cancel this run?

      New work will stop and older attempts will no longer be allowed to submit results. Existing artifacts and evidence remain in the history.

      Outstanding reservations are charged conservatively; unresolved provider costs still require reconciliation. Cancellation cannot undo an external action that already occurred.
